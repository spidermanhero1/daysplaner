# Дни

Личный список дел на день. Один человек, русский интерфейс, без часов и без чужих аккаунтов. Граница дня — UTC+7 (`Asia/Bangkok` в `shared/dates.ts`).

## Как устроено

- Экран дня: добавить, отметить, переименовать, убрать, перетащить, приоритет «обычное / важно». Сделанное в тот же день уходит вниз и бледнеет.
- Соседние дни и архив «сделанное». Кнопка «Хвост на …» переносит несделанное на следующий день.
- Телефон: поле ввода закреплено внизу. Компьютер: `n` новое, `j` `k` ход, `x` готово, `i` важно, `alt` и стрелки — порядок и день.
- База одна: `data/plandays.sqlite` (`better-sqlite3`). API на Hono, экран на Vite и React.
- `npm run dev` — без пароля, порты 5173 и 8787. В проде обязательны `PLANDAYS_PASSWORD` и HTTPS: либо `PLANDAYS_HTTPS=1` и `Caddyfile`, либо `PLANDAYS_TLS_CERT` и `PLANDAYS_TLS_KEY`. Переменные — в `.env.example`.

## Что не добавлять самому

Общие списки, регистрацию, календарь по часам, напоминания, секции «работа / дом» и лишние уровни важности. Секции и новые приоритеты — только если владелец скажет, что без них список разваливается.

## Дальше

Сначала пожить с текущим экраном и поправить то, что мешает руками. Хост для прода ещё не выбран: свой сервер, маленький VPS или доступ только из своей сети. Когда адрес будет ясен, выложить одну базу и один пароль, без публичной регистрации.
