# Дни

Личный список дел на день. Один дом и несколько профилей, русский интерфейс, без часов и без регистрации. Граница дня — UTC+7 (`Asia/Bangkok` в `shared/dates.ts`).

## Как устроено

- Профиль — человек: свои дни, покупки, перекуры и свой фон. Вход одним паролем на весь дом (`PLANDAYS_PASSWORD`). Какой профиль открыт, помнит браузер. В `npm run dev` без пароля вход выключен.
- Экран дня: добавить, отметить, переименовать, убрать, перетащить, приоритет «обычное / важно». Сделанное в тот же день уходит вниз и бледнеет.
- Соседние дни и архив «сделанное». Кнопка «Хвост на …» переносит несделанное на следующий день.
- Телефон: поле ввода закреплено внизу. Компьютер: `n` новое, `j` `k` ход, `x` готово, `i` важно, `alt` и стрелки — порядок и день.
- Дома база — файл `data/plandays.sqlite`. На Vercel файла нет, список лежит в Turso (`TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`). API на Hono, экран на Vite и React.
- `npm run dev` — порты 5173 и 8787, файл на диске. На Vercel HTTPS делает Vercel. Свой сервер: `PLANDAYS_HTTPS=1` и `Caddyfile`, либо `PLANDAYS_TLS_CERT` и `PLANDAYS_TLS_KEY`. Переменные — в `.env.example`.

## Что не добавлять самому

Общие списки, регистрацию, календарь по часам, напоминания, секции «работа / дом» и лишние уровни важности. Секции и новые приоритеты — только если владелец скажет, что без них список разваливается.
